# Image Gallery

## About the Project

Image Gallery is a responsive web project developed as part of my CodeAlpha internship tasks. It displays images in an organized gallery layout with a clean and user-friendly interface.

## Features

* Responsive image gallery layout
* Interactive image viewing
* Clean and visually appealing design
* Easy navigation between images

## Technologies Used

* HTML5
* CSS3
* JavaScript
